Full-stack e-commerce + restaurant management app built with React 18 + TypeScript, Redux, MUI v5, React Router v6, Axios.

**Key routes:** / (home), /menu, /menu/:cat/:product, /cupcakes, /restaurants, /careers, /profile, /checkout, /admin/*

**State:** Redux with Thunk; slices for users, products, categories, orders, restaurants, jobs, settings.

**Why:** Student project being upgraded to professional quality. Backend (Node/Mongo) already deployed; frontend being redesigned.

**How to apply:** When suggesting changes, keep class names stable (CSS-only redesign was done), avoid breaking Redux selectors or route params.
